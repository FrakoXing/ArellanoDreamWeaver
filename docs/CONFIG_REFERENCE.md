## 1. model — 模型参数

### model.name
- **类型**: `string`
- **默认值**: `"DreamWeaver-v1"`
- **说明**: 模型名称，用于日志和检查点命名
- **建议**: 修改为有意义的标识，如 `"DreamWeaver-v1-128bpm"`

### model.transformer — Transformer 参数

#### d_model
- **类型**: `int`
- **默认值**: `512`
- **取值范围**: 128 ~ 1024（建议为 2 的幂次）
- **说明**: 模型的核心维度，即每个 token 的嵌入向量维度。越大则模型容量越大，训练越慢
- **影响**: 
  - 增大 → 模型容量↑，显存↑，训练速度↓
  - 减小 → 模型容量↓，显存↓，训练速度↑
- **建议**: 
  - 快速实验: 256
  - 正常训练: 512
  - 高性能: 768 ~ 1024

#### n_heads
- **类型**: `int`
- **默认值**: `8`
- **取值范围**: 2 ~ 16（必须能被 `d_model` 整除）
- **说明**: 多头注意力的头数。每个头关注不同的特征子空间
- **约束**: `d_model % n_heads == 0`，每个头的维度为 `d_model / n_heads`
- **建议**: 
  - d_model=256 → n_heads=4
  - d_model=512 → n_heads=8
  - d_model=768 → n_heads=12
  - d_model=1024 → n_heads=16

#### n_layers
- **类型**: `int`
- **默认值**: `6`
- **取值范围**: 2 ~ 12
- **说明**: Transformer 编码器的层数。层数越多，模型对序列的建模能力越强
- **影响**: 每增加一层，参数量增加约 `4 * d_model^2`
- **建议**: 
  - 快速实验: 3 ~ 4
  - 正常训练: 6
  - 深度模型: 8 ~ 12

#### d_ff
- **类型**: `int`
- **默认值**: `2048`
- **取值范围**: 512 ~ 4096（通常为 `d_model * 4`）
- **说明**: 前馈网络 (FFN) 的中间层维度。Transformer 中每个注意力层后接一个 FFN
- **建议**: 通常保持 `d_model * 4`，如 d_model=512 → d_ff=2048

#### dropout
- **类型**: `float`
- **默认值**: `0.1`
- **取值范围**: 0.0 ~ 0.5
- **说明**: Dropout 概率，用于防止过拟合。训练时随机丢弃部分神经元
- **建议**:
  - 数据量小 (< 100): 0.2 ~ 0.3
  - 数据量大 (> 1000): 0.1
  - 数据量极大 (> 10000): 0.0 ~ 0.05

#### max_seq_len
- **类型**: `int`
- **默认值**: `4096`
- **取值范围**: 512 ~ 8192
- **说明**: 最大序列长度（音符数/时间步数）。超过此长度的序列会被截断
- **影响**: 显存消耗与序列长度成**平方关系**（因为注意力机制 O(n²)）
- **建议**:
  - 快速实验: 1024 ~ 2048
  - 正常训练: 4096
  - 长序列: 6144 ~ 8192（需大显存，如 24GB+）

### model.diffusion — Diffusion 参数

#### n_timesteps
- **类型**: `int`
- **默认值**: `1000`
- **取值范围**: 100 ~ 4000
- **说明**: 扩散过程的步数。步数越多，生成质量越高，训练/推理越慢
- **建议**:
  - 快速实验: 100 ~ 200
  - 正常训练: 1000
  - 高质量: 2000 ~ 4000

#### beta_start
- **类型**: `float`
- **默认值**: `0.0001`
- **取值范围**: 1e-5 ~ 1e-3
- **说明**: 噪声调度中的起始 beta 值。控制扩散过程初始噪声强度
- **建议**: 保持默认，一般不需要调整

#### beta_end
- **类型**: `float`
- **默认值**: `0.02`
- **取值范围**: 0.01 ~ 0.1
- **说明**: 噪声调度中的结束 beta 值。控制扩散过程最终噪声强度
- **建议**: 保持默认，一般不需要调整

#### schedule
- **类型**: `string`
- **默认值**: `"cosine"`
- **取值范围**: `"linear"`, `"cosine"`, `"sqrt"`
- **说明**: 噪声调度类型
  - `linear`: 线性增加噪声，简单直接
  - `cosine`: 余弦调度，优先在中间步数添加噪声，生成质量更好
  - `sqrt`: 平方根调度，噪声增加先快后慢
- **建议**: 
  - 默认使用 `cosine`（效果最好）
  - `linear` 适合快速实验
  - `sqrt` 特殊场景使用

### model.heads — 多任务头参数

#### note_prediction — 音符预测头
- `hidden_dim` (`int`, 默认 `256`): 隐藏层维度
- `num_classes` (`int`, 默认 `4`): 音符类型数 (tap, hold, slide, none)
- **说明**: 用于预测每个时间步的音符类型

#### bpm_prediction — BPM 回归头
- `hidden_dim` (`int`, 默认 `128`): 隐藏层维度
- **说明**: 预测谱面的 BPM 值（回归任务）

#### difficulty_assessment — 难度分类头
- `hidden_dim` (`int`, 默认 `128`): 隐藏层维度
- `num_classes` (`int`, 默认 `6`): 难度等级数 (EZ, NM, HD, IN, AT, LEGACY)
- **说明**: 分类谱面难度等级

#### style_classification — 风格分类头
- `hidden_dim` (`int`, 默认 `128`): 隐藏层维度
- `num_classes` (`int`, 默认 `10`): 音乐风格数
- **说明**: 分类谱面的音乐风格

## 2. training — 训练参数

### batch_size
- **类型**: `int`
- **默认值**: `32`
- **取值范围**: 1 ~ 256
- **说明**: 每个训练批次包含的样本数
- **影响**: 
  - 增大 → 训练更稳定，梯度估计更准确，显存↑
  - 减小 → 训练不稳定，更新频繁，显存↓
- **建议**: 
  - 显存 8GB: 8 ~ 16
  - 显存 16GB: 16 ~ 32
  - 显存 24GB+: 32 ~ 64

### learning_rate
- **类型**: `float`
- **默认值**: `0.0001`
- **取值范围**: 1e-6 ~ 1e-3
- **说明**: 初始学习率
- **建议**: 
  - Transformer 常用: 1e-4 ~ 3e-4
  - 小数据集: 1e-4（避免过拟合）
  - 大数据集: 3e-4 ~ 5e-4
  - 配合 warmup 使用

### weight_decay
- **类型**: `float`
- **默认值**: `0.01`
- **取值范围**: 0.0 ~ 0.1
- **说明**: L2 正则化权重，用于防止过拟合
- **建议**: 
  - 默认 0.01
  - 数据量大可减小到 0.001
  - 数据量小可增大到 0.05

### epochs
- **类型**: `int`
- **默认值**: `100`
- **取值范围**: 1 ~ 1000
- **说明**: 训练总轮数
- **建议**: 
  - Debug/测试: 2 ~ 5
  - 正常训练: 100 ~ 300
  - 完整训练: 500 ~ 1000（配合 early stopping）

### warmup_epochs
- **类型**: `int`
- **默认值**: `5`
- **取值范围**: 0 ~ epochs
- **说明**: 学习率预热轮数。在前 `warmup_epochs` 轮中，学习率从 0 线性增加到 `learning_rate`
- **目的**: 防止模型在训练初期因学习率过大而不稳定
- **建议**: 总 epoch 的 5% ~ 10%

### gradient_clip
- **类型**: `float`
- **默认值**: `1.0`
- **取值范围**: 0.1 ~ 10.0
- **说明**: 梯度裁剪阈值。梯度范数超过此值会被缩放到该值
- **建议**: 
  - 默认 1.0
  - 训练不稳定时增大到 2.0 ~ 5.0
  - 设置为 0 则禁用梯度裁剪

### loss_weights — 损失权重

各个任务的损失权重，控制不同任务在总损失中的占比。

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `note_prediction` | float | 1.0 | 音符预测损失权重 |
| `bpm_prediction` | float | 0.5 | BPM 回归损失权重 |
| `difficulty` | float | 0.3 | 难度分类损失权重 |
| `style` | float | 0.2 | 风格分类损失权重 |
| `diffusion` | float | 2.0 | 扩散损失权重 |

**说明**:
- `diffusion` 权重最高（2.0），因为扩散是核心任务，负责生成谱面结构
- `note_prediction` 次之（1.0），音符类型是谱面最重要的组成部分
- 其他辅助任务权重较低

**调整建议**:
- 如果生成的谱面音符类型不准 → 增大 `note_prediction`
- 如果生成的谱面结构混乱 → 增大 `diffusion`
- 如果 BPM 预测不准 → 增大 `bpm_prediction`

### optimizer
- **类型**: `string`
- **默认值**: `"adamw"`
- **取值范围**: `"adamw"`, `"adam"`, `"sgd"`
- **说明**: 优化器类型
  - `adamw`: Adam with decoupled weight decay（推荐，最常用）
  - `adam`: 标准 Adam
  - `sgd`: 随机梯度下降（需要更多调参）
- **建议**: 使用默认 `adamw`

### scheduler
- **类型**: `string`
- **默认值**: `"cosine"`
- **取值范围**: `"cosine"`, `"linear"`, `"constant"`, `"step"`
- **说明**: 学习率调度策略
  - `cosine`: 余弦退火，学习率从初始值按余弦曲线下降到 0
  - `linear`: 线性衰减
  - `constant`: 恒定学习率
  - `step`: 阶梯式衰减（每 N 个 epoch 减半）
- **建议**: 使用默认 `cosine`

### use_real_audio
- **类型**: `bool`
- **默认值**: `true`
- **取值范围**: `true`, `false`
- **说明**: 是否使用真实音频特征
  - `true`: 从 `data/audio/` 加载对应音频文件，提取梅尔频谱
  - `false`: 使用随机噪声作为音频特征（仅用于测试训练流程）
- **建议**: 有音频数据时设置为 `true`

### cache_audio_features
- **类型**: `bool`
- **默认值**: `true`
- **取值范围**: `true`, `false`
- **说明**: 是否缓存音频特征到内存。首次加载后缓存在 RAM 中，避免重复处理
- **影响**: 
  - `true`: 加速训练（尤其大数据集），但消耗大量 RAM
  - `false`: 节省 RAM，但每个 epoch 都重新处理音频
- **建议**: 
  - 数据量 < 200: `true`
  - 数据量大且 RAM 不足: `false`

### demo_samples
- **类型**: `int`
- **默认值**: `32`
- **取值范围**: 1 ~ 256
- **说明**: 当没有真实数据时，演示数据集的大小
- **建议**: 保持默认

## 3. data — 数据参数

### data.raw_dir
- **类型**: `string`
- **默认值**: `"data/raw"`
- **说明**: 原始数据目录（可选，用于存放未处理的原始谱面文件）
- **建议**: 保持默认

### data.processed_dir
- **类型**: `string`
- **默认值**: `"data/processed"`
- **说明**: 处理后谱面 JSON 文件目录。训练脚本扫描此目录下的 `.json` 文件
- **建议**: 保持默认

### data.audio_dir
- **类型**: `string`
- **默认值**: `"data/audio"`
- **说明**: 音频文件目录。训练时根据谱面文件名在此目录查找对应的音频文件
- **文件匹配规则**: `Calm.json` ↔ `Calm.mp3`（通过文件名 stem 匹配）
- **支持格式**: `.mp3`, `.wav`, `.flac`, `.ogg`, `.m4a`, `.aac`
- **建议**: 保持默认

### data.cache_dir
- **类型**: `string`
- **默认值**: `"data/cache"`
- **说明**: 音频特征缓存目录。预处理时提取的音频特征会保存到此目录
- **建议**: 保持默认

### data.max_seq_len
- **类型**: `int`
- **默认值**: `4096`
- **取值范围**: 512 ~ 8192
- **说明**: 最大序列长度（与 `model.transformer.max_seq_len` 保持一致）
- **建议**: 与模型配置中的 `max_seq_len` 保持一致

### data.audio — 音频特征参数

#### sample_rate
- **类型**: `int`
- **默认值**: `22050`（旧版 `44100`）
- **取值范围**: 16000 ~ 48000
- **说明**: 音频采样率 (Hz)。所有音频文件会被重采样到此采样率
- **影响**: 
  - 高采样率 → 保真度↑，计算量↑，特征维度↑
  - 低采样率 → 保真度↓，计算量↓，特征维度↓
- **建议**: 
  - 节奏游戏通常 22050 Hz 足够
  - 高保真需求: 44100 Hz

#### n_mels
- **类型**: `int`
- **默认值**: `128`
- **取值范围**: 64 ~ 256
- **说明**: 梅尔滤波器数量，即梅尔频谱图的频率维度
- **建议**: 
  - 快速实验: 64
  - 正常训练: 128
  - 高精度: 256

#### hop_length
- **类型**: `int`
- **默认值**: `512`
- **取值范围**: 128 ~ 2048
- **说明**: 帧移（采样点数），控制时间分辨率。越小时间分辨率越高
- **影响**: 
  - 小 hop_length → 时间分辨率↑，序列长度↑，计算量↑
  - 大 hop_length → 时间分辨率↓，序列长度↓，计算量↓
- **建议**: 保持默认 512

#### n_fft
- **类型**: `int`
- **默认值**: `2048`
- **取值范围**: 512 ~ 4096
- **说明**: FFT 窗口大小，控制频率分辨率
- **建议**: 保持默认 2048

#### feature_dim
- **类型**: `int`
- **默认值**: `128`
- **取值范围**: 64 ~ 256
- **说明**: 音频特征维度（通常与 `n_mels` 一致）
- **建议**: 与 `n_mels` 保持一致

### data.chart — 谱面特征参数

#### max_notes_per_segment
- **类型**: `int`
- **默认值**: `64`
- **取值范围**: 16 ~ 256
- **说明**: 每个段落的最大音符数，用于谱面解析
- **建议**: 保持默认

#### time_quantization
- **类型**: `int`
- **默认值**: `16`
- **取值范围**: 4, 8, 16, 32, 64
- **说明**: 时间量化精度。`16` 表示 1/16 拍精度
- **建议**: 
  - 简单谱面: 8
  - 标准谱面: 16
  - 高精度谱面: 32 ~ 64

#### feature_dim
- **类型**: `int`
- **默认值**: `8`
- **取值范围**: 4 ~ 16
- **说明**: 谱面特征维度。每个音符编码为 `feature_dim` 维向量
- **默认维度说明**:
  - 0: 音符类型 (0=none, 0.33=tap, 0.66=hold, 1.0=slide)
  - 1: 位置 X (归一化到 0~1)
  - 2: 上下轨道 (0=下, 1=上)
  - 3: Hold 时长 (归一化)
  - 4: 音符密度 (基于时间间隔)
  - 5: 是否假音
  - 6: 同时间是否有其他音符
  - 7: 时间间隔
- **建议**: 保持默认 8

## 4. LLM — LLM 参数

### provider
- **类型**: `string`
- **默认值**: `"openai"`
- **取值范围**: `"openai"`, `"local"`
- **说明**: LLM 提供商
  - `openai`: 使用 OpenAI API（GPT-4, GPT-3.5）
  - `local`: 使用本地模型（如 Ollama, llama.cpp）
- **当前状态**: 预留功能，尚未集成到训练流程中

### model
- **类型**: `string`
- **默认值**: `"gpt-4-turbo"`
- **说明**: LLM 模型名称
- **当前状态**: 预留功能

### temperature
- **类型**: `float`
- **默认值**: `0.7`
- **取值范围**: 0.0 ~ 2.0
- **说明**: LLM 生成温度。值越高，输出越随机
- **当前状态**: 预留功能

### max_tokens
- **类型**: `int`
- **默认值**: `1024`
- **取值范围**: 64 ~ 4096
- **说明**: LLM 最大生成 token 数
- **当前状态**: 预留功能

## 5. logging — 日志参数

### log_dir
- **类型**: `string`
- **默认值**: `"logs"`
- **说明**: 日志和检查点保存目录
- **建议**: 保持默认，或按实验命名，如 `"logs/exp001"`

### save_every
- **类型**: `int`
- **默认值**: `10`
- **取值范围**: 1 ~ epochs
- **说明**: 每 N 个 epoch 保存一次检查点
- **建议**: 
  - 快速实验: 1
  - 正常训练: 10
  - 长时间训练: 20 ~ 50

### tensorboard
- **类型**: `bool`
- **默认值**: `true`
- **取值范围**: `true`, `false`
- **说明**: 是否启用 TensorBoard 日志记录
  - `true`: 记录 loss、学习率等曲线，可用 `tensorboard --logdir logs/` 查看
  - `false`: 不记录
- **建议**: 保持 `true`

### verbose
- **类型**: `bool`
- **默认值**: `true`
- **取值范围**: `true`, `false`
- **说明**: 是否输出详细训练日志
  - `true`: 每个 batch 打印 loss
  - `false`: 只打印 epoch 级统计
- **建议**: 保持 `true`

| `max_seq_len` | 4096 | 1024 | 4096 | 4096 |
| `n_timesteps` | 1000 | 100 | 1000 | 2000 |

### 训练参数

| 参数 | 默认值 | 小显存 (8GB) | 中显存 (16GB) | 大显存 (24GB+) |
|------|--------|-------------|--------------|---------------|
| `batch_size` | 32 | 4 ~ 8 | 16 ~ 32 | 32 ~ 64 |
| `learning_rate` | 1e-4 | 1e-4 | 1e-4 | 2e-4 |
| `epochs` | 100 | 50 | 100 | 200 |
| `gradient_clip` | 1.0 | 1.0 | 1.0 | 1.0 |

### 数据参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `sample_rate` | 22050 | 通常不需要改 |
| `n_mels` | 128 | 64 快速 / 128 标准 / 256 高精度 |
| `feature_dim` (audio) | 128 | 与 n_mels 一致 |
| `feature_dim` (chart) | 8 | 固定值，不要改 |

## 7. 调参建议

### 场景 1: 快速验证训练流程

```yaml
model:
  transformer:
    d_model: 256
    n_heads: 4
    n_layers: 3
    d_ff: 1024
    max_seq_len: 1024
  diffusion:
    n_timesteps: 100
training:
  batch_size: 4
  epochs: 5
  warmup_epochs: 1
  use_real_audio: false
```

### 场景 2: 正常训练（推荐）

```yaml
model:
  transformer:
    d_model: 512
    n_heads: 8
    n_layers: 6
    d_ff: 2048
    max_seq_len: 4096
  diffusion:
    n_timesteps: 1000
training:
  batch_size: 16
  epochs: 200
  warmup_epochs: 10
```
